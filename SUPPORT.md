# Support

## Questions and usage help

After GitHub Discussions is enabled, use Discussions for setup questions, design conversations and general help. Search existing documentation and discussions first.

## Bugs

Use the GitHub bug report form for reproducible defects. Include your Windows version, .NET SDK version, application revision and a minimal synthetic sample when the issue concerns data parsing.

Never upload customer data or secrets. Replace sensitive material with a deliberately synthetic reproduction.

## Feature ideas

Use the feature proposal form. Describe the business problem, expected outcome and relationship to the current MVP. Ideas outside v1.0 may be retained for later without being scheduled.

## Security

Follow [SECURITY.md](SECURITY.md) and report vulnerabilities privately. Security reports and accidental data exposure do not belong in public issues or discussions.

## Support level

This is currently a portfolio project under active development. No commercial support, uptime commitment or response-time guarantee is provided.
