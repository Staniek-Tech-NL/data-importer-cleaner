# Architecture decision records

Architecture decision records (ADRs) capture choices that are expensive to rediscover. They describe context, decision and consequences rather than repeating code.

| ADR | Decision | Status |
| --- | --- | --- |
| [0001](0001-domain-model-and-value-lifecycle.md) | Domain terminology and cell value lifecycle | Accepted |
| [0002](0002-separate-validation-and-cleaning.md) | Separate validation and cleaning with two validation passes | Accepted |
| [0003](0003-deterministic-duplicate-matching.md) | Deterministic normalized duplicate matching | Accepted |

New ADRs use the next four-digit number. Existing accepted ADRs are superseded rather than rewritten when the decision changes materially.
